Digidirect PreOrder
=====================

[wiki link](https://wiki.digidirect.com/display/LEGO/Pre-Order)

### VERSION 1.0.0

Allow buyers to easily pre-order or backorder goods that are unavailable for immediate delivery.

  - Allow shoppers to pre-order upcoming or out of stock items
  - Use pre order function for simple, configurable, grouped or bundle products
  - Create custom pre-order buttons and notes
