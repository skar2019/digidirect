Ewave blog infinite scroll
=====================

[wiki link](https://wiki.ewave.com/display/LEGO/%5BBlog%5D+Infinity+Scroll)

### VERSION 1.0.0
  1. Admin is able to: 
    - enable/disable infinite scroll functionality for post listing and category listing pages 
  
  2. User is able:
    - to see "Load more" button
    - click "Load More" button and see loaded reviews
    - to see default magento pagination if extension is disabled
  
##### Information for developers
  1. default magento reviews pager template was overwritten - to be hidden if IS is enabled
  2. It is add-on - "Ewave_InfiniteScroll" is required to be installed
