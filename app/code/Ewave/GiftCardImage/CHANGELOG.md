1.0.0
=============
* New features:
    * [#180498](https://ewave.tpondemand.com/entity/180498) -- Gift Card Images. Solution Architecture
* Solution Architecture:
    * [#180499](https://ewave.tpondemand.com/entity/180499) -- GIFT CARD IMAGES. As an admin, I want to be able to see Gift Card Image grid with all images
    * [#180500](https://ewave.tpondemand.com/entity/180500) -- GIFT CARD IMAGES. As an admin, I want to be able to upload Image and specify settings for it (see description)
    * [#180501](https://ewave.tpondemand.com/entity/180501) -- PRODUCT SETTING. As an admin, I want to be able to set gift card images for a product
    * [#180502](https://ewave.tpondemand.com/entity/180502) -- PRODUCT PAGE. As a user, I want to be able to select image for Gift Card
    * [#180503](https://ewave.tpondemand.com/entity/180503) -- CART PAGE. As a user, I want to see selected gift card image in Cart and on Checkout
    * [#181549](https://ewave.tpondemand.com/entity/181549) -- ORDER PAGE. As an admin, I want to see what Gift Image was selected for the Order
    * [#185267](https://ewave.tpondemand.com/entity/185267) -- EMAIL. As a user, I want to receive Gift Card email with image that I selected
    * [#185268](https://ewave.tpondemand.com/entity/185268) -- WISHLIST. As a user, I want to be able to add Gift Card product to Wishlist
    * [#180882](https://ewave.tpondemand.com/entity/180882) -- GENERAL SETTINGS. As an admin, I want to be able to Enable/Disable Gift Card Images module
